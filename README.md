# Pixelmation 2.0

**Живая версия: https://pixelmation2.vercel.app**

Редактор пиксельных текстур и покадровых анимаций. Ремастер первой версии: те же
форматы `.pxlmt` и `.pxlma`, но современный стек, тёмная тема, canvas-рендер,
история отмен, drag-and-drop, экспорт в PNG и анимированный GIF — и встроенный
API, через который редактором управляет агент (Claude), а не только человек.

## Быстрый старт

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # сборка в dist/
npm run test:run   # тесты ядра, состояния и API агента
npm run pxl -- help  # командная строка редактора
```

## Что умеет

**Текстура** — холст произвольного размера от 1×1 до 512×512 (в оригинале было
максимум 75×75). ЛКМ рисует, ПКМ работает пипеткой, зажатая кнопка ведёт линию
без разрывов. Инструменты: кисть, ластик, заливка области, линия, прямоугольник,
эллипс, пипетка, перемещение всего рисунка. Цвет — с альфа-каналом; палитра
холста собирается автоматически и доступна в один клик. Фон холста и фон
приложения настраиваются отдельно.

**Анимация** — кадры, где каждая клетка хранит не цвет, а ссылку на пиксель
привязанной текстуры. Превью текстуры в панели слева: клик выбирает ссылку,
ПКМ по холсту копирует ссылку из кадра. Кадры добавляются, копируются,
удаляются и переставляются перетаскиванием на таймлайне; есть буфер обмена
кадров, вставка текстуры целиком как кадра и проигрывание с настраиваемой
скоростью. Вкладка «Текстура» позволяет подправить текстуру не выходя из
анимации — при возврате повисшие ссылки чистятся сами.

**Общее для обоих режимов** — состояние живёт в zustand с `persist`, поэтому
случайная перезагрузка не теряет работу; при закрытии вкладки с несохранёнными
изменениями браузер переспрашивает. Файлы открываются перетаскиванием в окно.
История отмен — 100 шагов, мазок мышью считается одним действием.

## Восстановление

Пока идёт работа, редактор сам складывает её состояния в локальный архив
(IndexedDB): последние 300 снимков текстур и анимаций, включая те, что были
стёрты или заменены новым документом. Кнопка ⟲ в шапке есть на всех экранах —
внутри список с превью (анимации проигрываются), а рядом кнопки «Восстановить»
и «Скачать». Снимки хранятся сжатыми, поэтому 300 состояний занимают считанные
сотни килобайт.

## Горячие клавиши

| Клавиши | Действие |
| --- | --- |
| `A` / `←` | предыдущий кадр (с первого — на последний) |
| `D` / `→` | следующий кадр (с последнего — на первый) |
| `Ctrl+Z` | отменить |
| `Ctrl+Shift+Z`, `Ctrl+Y` | вернуть отменённое |
| `Ctrl+S` | сохранить файл |
| `E` | прозрачность как текущий цвет (или пустая ссылка) |
| `G` | инструмент «заливка» |
| `F` | инструмент «двигать изображение» |
| `B` / `X` / `I` | кисть / ластик / пипетка |
| `L` / `R` / `O` | линия / прямоугольник / эллипс |
| `Shift+G` | показать или скрыть сетку (по умолчанию выключена) |
| `Пробел` | проиграть анимацию |
| `?` | справка |

Бинды привязаны к физическим клавишам (`event.code`), поэтому работают и на
русской раскладке.

## Форматы

`.pxlmt` — текстура, `.pxlma` — анимация вместе со своей текстурой. Оба —
обычный JSON, читаемый глазами:

```json
{ "name": "герой", "cells": [["#ff0000ff", null], [null, "#00ff0080"]] }
```

Файлы первой версии Pixelmation (там `cells` и `slides` были RLE-строками)
открываются без конвертации; при сохранении можно попросить старый формат
галочкой «Формат Pixelmation 1.x». Подробности — в [docs/formats.md](docs/formats.md).

## Инструменты агента

Приложение задумано так, чтобы им мог пользоваться не только человек:

- в браузере есть объект `window.pixelmation` — рисование, кадры, экспорт,
  текстовое превью холста (`pixelmation.help()` покажет список);
- в терминале есть `npm run pxl` — создание файлов, рисование, ASCII-превью,
  рендер PNG и сборка GIF без всякого интерфейса.

```bash
npm run pxl -- new texture hero.pxlmt 16 16
npm run pxl -- draw hero.pxlmt --rect 2,2,13,13,"#6d8bffff" --fill 7,7,"#3ddcedff"
npm run pxl -- show hero.pxlmt --rulers
npm run pxl -- render hero.pxlmt hero.png --scale 12
```

Полный справочник — [docs/agent-api.md](docs/agent-api.md).

## Структура

```
src/core/     чистое ядро: форматы, сетки, рендер, PNG- и GIF-энкодеры
src/state/    zustand-хранилище редактора с историей и persist
src/ui/       React-компоненты интерфейса
src/agent/    window.pixelmation — руки агента в браузере
src/services/ файлы, экспорт картинок, уведомления
tools/pxl.ts  командная строка
docs/         документация
Pixelmation/  исходники первой версии, оставлены как справочник
```

Подробнее — [docs/architecture.md](docs/architecture.md) и
[docs/design-system.md](docs/design-system.md).

## Тесты

```bash
npm run test:run
```

Покрыты разбор и запись обоих форматов (включая legacy), операции над сетками,
логика кадров, история отмен, PNG- и GIF-энкодеры (GIF проверяется собственным
LZW-декодером) и весь API агента.
