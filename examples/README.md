# Примеры

Сюда кладутся эталонные анимации и текстуры — то, что получилось хорошо и
на что стоит равняться. Агент читает эту папку перед рисованием, чтобы
перенять стиль: палитру, размер холста, длину цикла, характер движения.

## Что класть

- `имя.pxlma` — сама анимация (внутри уже лежит её текстура);
- `имя.pxlmt` — отдельная текстура, если пример про статику;
- `имя.gif` — необязательно, но помогает человеку посмотреть глазами;
- строку про пример в таблицу ниже.

Файлы кладите как есть, из редактора («Скачать») или из CLI. Руками JSON не
правьте. Сохраняется всё в одном формате — сетка упакована в строку, так что
после `pxl draw` ничего пересохранять не нужно.

## Как агент этим пользуется

```bash
npm run pxl -- info examples/имя.pxlma            # размер, число кадров, палитра
npm run pxl -- show examples/имя.pxlma --slide 1 --rulers
npm run pxl -- gif examples/имя.pxlma /tmp/x.gif  # собрать и посмотреть
```

## Каталог

Сет 25×25 про одну девушку и её путь внутри тела. Всё, кроме `gulp.pxlma`, —
это **желудок изнутри**: розово-красные стенки, тёмно-бордовый контур, свет
слева-сверху. Порядок по сюжету:

| Файл | Кадров | Что показывает |
| --- | --- | --- |
| `gulp1.pxlma` | 5 | Проглатывание: девушка идёт сверху вниз, желудок раздувается снизу (57→155 клеток) |
| `rGulp1.pxlma` | 5 | Тот же кадр-в-кадр наоборот — обратный ход. Текстура `stomach_red` |
| `gulp2.pxlma` | 6 | Девушка целиком втягивается в полость и укладывается внутри |
| `step1.pxlma` | 4 | Короткий луп: желудок шевелится, девушка ещё торчит сверху |
| `clothes.pxlma` | 6 | Она внутри, одетая. Движение стенок |
| `naked.pxlma` | 6 | То же движение, одежда уже переварена |
| `acid1.pxlma` | 6 | Полость наливается белой кислотой, тело ещё читается |
| `acid2.pxlma` | 6 | Кислота поднялась выше, силуэт почти скрыт под поверхностью |
| `acid3.pxlma` | 6 | Девушки нет, пустой желудок сжимается, летят белые брызги кислоты |
| `gulp.pxlma` | 6 | Другое место: **кишечник** — толстый тёмный по краю, тонкий светлее в центре (текстура `bunny`). Девушку втягивает снизу вверх в толстый |

## Приёмы, которые здесь стоит перенимать

- **Одна маска — разные ссылки.** `acid1`, `acid2`, `clothes`, `naked`
  покадрово идентичны по силуэту и различаются только тем, на какие пиксели
  текстуры ссылаются. Так делаются варианты (одетая / голая / стадия кислоты)
  без перерисовки движения.
- **Реверс отдельным файлом.** `rGulp1` — зеркало `gulp1` по времени.
- **Узор борозд кишечника.** Эталон — кадр 1; в остальных кадрах он не
  перерисовывается, а едет вместе с контуром (сдвиг подбирается по совпадению
  контура) и обрезается по краю зоны. Пустоты после обрезки достраиваются
  линиями, а не точками: каждая линия входит в стенку или в другую линию,
  одиночная клетка — только как перемычка между двумя стенками. Держать
  35–43% борозд от площади зоны; приближая узор к другому кадру, клетки
  добавляют, а не вырезают. Бликов не ставим.
- **Стык анимаций.** Последний кадр `gulp` совпадает с первым кадром `step`
  клетка в клетку, а кадры 4–5 `gulp` постепенно подводят узор к нему.
- **Луп из 4–6 кадров** и палитра на 13–38 задействованных цветов из 256.
  Кожа `#ac7070`, тени `#3b0202`/`#230101`, акценты `#b90909`/`#d04949`,
  кислота и блики `#c2c2c2`/`#949494`.
