# Pixelmation 2.0 — заметки для агента

Редактор пиксельных текстур (`.pxlmt`) и анимаций (`.pxlma`). Ремастер первой
версии; её исходники лежат в `Pixelmation/` как справочник и не собираются.

## Команды

```bash
npm run dev        # дев-сервер на http://localhost:3000
npm run build      # tsc + vite build
npm run test:run   # vitest, всё разом
npm run pxl -- help  # командная строка редактора
```

## Правила работы с кодом

- Ядро (`src/core`) не знает ни про React, ни про DOM — новые операции над
  холстом добавляются туда и покрываются тестами.
- Хранилище (`src/state/store.ts`) — единственный источник правды документа.
  UI и `window.pixelmation` вызывают одни и те же действия, поэтому история
  отмен и автосохранение работают одинаково.
- Сетка индексируется `grid[y][x]`, точка — `{x: столбец, y: строка}`.
  Оси меняются местами только в файле — при чтении и записи (`src/core/codec.ts`).
- Тексты интерфейса и комментарии — по-русски.
- Дизайн-система описана в `docs/design-system.md`; цвета берём только из
  CSS-переменных.

## Как рисовать самому

Перед новой анимацией или текстурой загляни в `examples/` — там лежат
эталонные `.pxlma`/`.pxlmt`, с которых берётся палитра, размер и характер
движения (`npm run pxl -- info examples/файл`, затем `show`).

В браузере: `window.pixelmation` (см. `docs/agent-api.md`), быстрее всего —
`pixelmation.drawAscii(rows, legend, origin)` и `pixelmation.preview()` для
проверки результата.

В терминале: `npm run pxl -- draw файл --ascii "..#|.#." --legend "#=#ff0000ff"`,
затем `npm run pxl -- show файл --rulers` или `render` в PNG.
