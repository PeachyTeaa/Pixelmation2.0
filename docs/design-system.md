# Дизайн-система

Все цвета — CSS-переменные на `:root` в `src/styles/tokens.css`. Тема
переключается классом `theme-dark` / `theme-light` на `<html>`; класс ставится
инлайн-скриптом в `index.html` до отрисовки, поэтому вспышки чужого фона нет.
Светлая тема переопределяет только переменные — компоненты не дублируются.

## Палитра (тёмная)

| Переменная | Значение | Где |
| --- | --- | --- |
| `--bg` | `#0b0e14` | фон страницы |
| `--bg-subtle` | `#0f131b` | вложенные зоны, модалки |
| `--surface` | `rgba(255,255,255,.045)` | карточки и панели |
| `--surface-2` | `rgba(255,255,255,.07)` | шапки, поля |
| `--border` / `--border-strong` | `rgba(255,255,255,.09)` / `.16` | границы |
| `--text` / `--text-2` / `--text-3` | `#e9ecf2` / `#9aa4b8` / `#6d7789` | текст |
| `--brand` / `--accent` | `#6d8bff` / `#3ddced` | акценты |
| `--gradient` | `linear-gradient(135deg,#3b5bfd,#6d5cf7 55%,#22d3ee)` | точечно |
| `--success` / `--danger` / `--warning` | `#12b76a` / `#f04438` / `#f79009` | статусы |

## Правила, которым следует интерфейс

1. **Градиент точечно.** Только заливка главной кнопки, полоска 3px сверху у
   плиток-показателей (`::after`) и одно слово в логотипе. Остальное монохромно.
2. **Кнопки светятся, а не отбрасывают тень.** `primary` при наведении получает
   `0 6px 18px rgba(59,91,253,.32)` — тень цветом бренда.
3. **Шапка приклеена и полупрозрачна:** `rgba(11,14,20,.72)` плюс
   `backdrop-filter: saturate(180%) blur(14px)`.
4. **Входной экран отличается от рабочего.** На стартовом экране два радиальных
   пятна `blur(120px)` в противоположных углах (синее и бирюзовое, `opacity`
   0.2–0.28) и одна стеклянная карточка по центру. Рабочий экран — спокойный
   фон и максимум читаемости.
5. **Никаких прижатых к краям блоков:** боковые поля `clamp(1rem, 3vw, 2.5rem)`,
   контейнер центрируется с `max-width: 1440px`.

## Типографика

Inter подключён локально пакетом `@fontsource-variable/inter` (не с CDN).
База 15px, `line-height 1.55`, `letter-spacing -.006em`. Заголовки — вес 650,
`letter-spacing -.022em`. Цифры везде `font-variant-numeric: tabular-nums`.

Мелкие подписи — 0.74rem, UPPERCASE, `letter-spacing .05em`, цвет `--text-2`.
Этим стилем оформлены лейблы полей, заголовки панелей и названия плиток: он
даёт интерфейсу характер.

## Геометрия и тени

Радиусы 8 / 12 / 16 / 22 px и pill (999px). Тени мягкие и глубокие:
`0 8px 24px rgba(0,0,0,.45)`, крупные модалки — `0 24px 60px rgba(0,0,0,.55)`.
Карточки: `--surface` + 1px `--border` + `backdrop-filter: blur(12px)`.

## Что учтено из подводных камней

- `input:-webkit-autofill` перебит через `-webkit-box-shadow: 0 0 0 1000px var(--bg-subtle) inset`;
- иконки календаря и времени в тёмной теме — `filter: invert(1)`;
- `<option>` рисует ОС, поэтому цвет и фон заданы явно;
- скроллбары стилизованы под тему;
- при `prefers-reduced-motion` анимации отключаются.

## Чего нет

Чистого чёрного и чистого белого, ярких заливок на больших площадях, тяжёлых
анимаций на рабочих экранах, теней с цветом по умолчанию и градиентных фонов
у карточек.
